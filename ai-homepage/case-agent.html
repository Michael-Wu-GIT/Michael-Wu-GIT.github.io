个人 AI 数字分身系统

基于 Hermes / OpenClaw 双引擎搭建的常驻 Mac 数字分身

深色界面中展示消息、知识库和自动化任务卡片

案例分类

AI 智能体 / Agent 开发

日常被微信、邮件、会议纪要切碎的时间，是知识工作者最常见但又难以批量处理的痛点。通用聊天机器人不懂自己的业务，无法理解企业内部的知识体系。

本项目将任务拆解为可编排的 Agent 步骤链，建立「文档解析 → 结构化提取 → 一致性校验」的处理流水线，将原本需要人工逐份处理的重复性材料，转化为可自动化、可追溯的流程化作业。

难点

日常被微信、邮件、会议纪要切碎时间，通用聊天机器人不懂自己的业务。

方案

基于 Hermes / OpenClaw 双引擎搭建常驻 Mac 数字分身：微信 + 邮箱双通道接入、中文语音输入、私有知识库随问随答、定时任务自动出周报简报。

结果

从 0 到 1 上线并稳定运行，日常消息处理与资料检索明显提效；同款架构可为客户定制。

架构设计

1

双引擎构架

Hermes 负责长时记忆推理，OpenClaw 负责工具调用与桥接。两者协同，覆盖从理解到执行的完整闭环。

2

多通道输入

微信与邮箱双通道实时监听，中文语音输入转写为文本后进入 Agent 流水线，保证信息不遗漏。

3

私有知识库

企业内部文档、台账、政策通过 RAG 检索引擎向量化，随问随答，数据永远留在本地。

4

定时自动化

每周报告、数据周报等定时任务自动触发，汇总当周关键信息并发送给指定人员。

关键技术

· Hermes / OpenClaw 双引擎 Agent 运行时
· RAG 检索 私有知识库向量检索
· macOS 后台常驻 开机自启 + 内存优化
· 语音输入 中文语音转写 + 意图识别
