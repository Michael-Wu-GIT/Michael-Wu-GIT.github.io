咨询提示词模板库 + 交付物自动化

11 场景 Prompt 库管理 + Word / PPT 自动生成

案例分类

AI 应用定制

报告、纪要、方案重复劳动量大，AI 直出质量不稳定、不可控。单靠人工检查，既效率低下又容易漏判。

本项目建立「版本化四条铁律」管理的 11 场景 Prompt 库（报告写作 / 深度分析 / 需求分析等），配套 Word / PPT 自动生成脚本。

难点

报告、纪要、方案重复劳动量大，AI 直出质量不稳定、不可控。

方案

按"版本化四条铁律"管理的 11 场景 Prompt 库（报告写作 / 深度分析 / 需求分析等），配套 Word / PPT 自动生成脚本，每场景留档失败案例持续迭代。

结果

标准化交付物产出效率显著提升，模板体系已沉淀为可复用资产。

架构设计

1

版本化四条铁律

每次迭代锁定：场景定义 / 输出标准 / 校验清单 / 失败案例。四条铁律贯穿整个 Prompt 设计流程，保证可复现性。

2

11 场景 Prompt 库

覆盖报告写作、深度分析、需求分析、方案生成等 11 个常见场景，模板沉淀后直接复用。

3

Word / PPT 自动生成

脚本读取 Prompt 输出，通过模板引擎自动填充到 Word / PPT，直接生成规范交付件。

4

失败案例留档

每次 AI 输出不达标，自动记录输入 / 输出 / 评分，供下次迭代时训练优化。

关键技术

· Prompt 版本管理 Git 化管理 + 校验清单
· 自动化脚本 Word / PPT 模板引擎
· 质量控制闭环 人工评分 + 自动留档
· 11 场景库 报告 / 分析 / 方案 / 会议纪要等
